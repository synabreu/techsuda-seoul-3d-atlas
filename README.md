# Seoul 3D Atlas

서울 25개 자치구와 주변 지형을 웹 브라우저에서 탐색하는 인터랙티브 3D 도시 아틀라스다. 공개 지도에 교통, 관광, 숙박, 등산로, 주택 정보를 연결해 서울을 한 화면에서 둘러볼 수 있도록 만들었다.

> 정밀 디지털 트윈이나 모든 정보를 실시간으로 제공하는 여행·부동산 서비스가 아니라, 공개 데이터를 연결해 서울을 새로운 방식으로 탐색하는 프로젝트다.

[**SEOUL — 3D Atlas v5.4 실행하기**](https://seoul-3d-atlas-new.synabreu.chatgpt.site/)

## 주요 기능

- 서울 25개 자치구와 약 26만 7천 개 건물을 3D로 표현한다.
- 지도를 회전·확대·축소·이동하고 14개 주요 랜드마크를 자동 비행으로 둘러볼 수 있다.
- 지하철 22개 노선·624개 역의 경로와 경유역, 버스 노선·방면·정류장을 탐색할 수 있다.
- 등산로, 문화재·관광 명소, 호텔·숙소의 위치와 정보를 확인할 수 있다.
- 아파트 매매 실거래가와 전세 보증금을 선택적으로 표시한다. 가격 표시는 기본적으로 꺼져 있다.
- 한국어·영어·일본어·중국어 간체·스페인어·프랑스어·이탈리아어를 지원한다.
- KRW·USD·JPY·CNY·EUR 통화 표시를 지원한다.
- 낮·노을·야경·비·눈과 봄·여름·가을·겨울을 조합해 도시 분위기를 바꿀 수 있다.
- 데스크톱 마우스와 모바일 터치 조작을 지원한다.

## 규모와 기술

| 항목 | 내용 |

| 높이 표현 | 원본 높이와 추정 높이를 함께 사용하며 확대 수준에 따라 과장을 줄임 |

초기 지도 생성과 첫 검증에는 43분 38초가 걸렸다. 이 수치는 최초 지도 구축 기록이며, 현재 v5.4 전체 개발 시간을 뜻하지 않는다.

## 데이터와 출처

건물·도로·수계는 [OpenStreetMap](https://www.openstreetmap.org/copyright) 계열 공개 지도 데이터를 바탕으로 구성했다. 지도 표현에는 [OpenFreeMap](https://openfreemap.org/) 및 [OpenMapTiles](https://openmaptiles.org/) 호환 방식을 참고했으며, 지형에는 공개 표고 데이터를 사용했다.

교통·관광·숙박·등산로·주택 정보는 공개 데이터의 스냅샷을 사용한다. 데이터별 정확한 원본 URL, 스냅샷 날짜, 라이선스가 확인되지 않은 경우 임의로 특정 제공자를 적지 않는다.

## 제한사항

- 건물은 서울 전체를 브라우저에서 표시하기 위해 단순화했다. 높이 정보가 없는 건물에는 층수나 기본값 기반 추정치가 포함될 수 있다.
- 지하철 데이터는 2026년 5월 31일 기준 스냅샷이며 실시간 도착, 지연, 막차, 요금을 제공하지 않는다.
- 버스와 지하철 경로 및 예상 시간은 데이터 기반 참고 정보이며 실제 이동 경로와 다를 수 있다.
- 날씨, 계절, 차량, 선박의 움직임은 시각적 연출이며 현재 서울의 실시간 상태가 아니다.
- 부동산 가격은 정보 탐색용이며 감정가나 AI 가격 예측 결과가 아니다.
- 호텔 표시는 실시간 객실 재고나 예약 가능 여부를 보장하지 않는다.
- 모바일 조작은 지원하지만 기기별 FPS를 정량적으로 측정한 결과는 아직 없다.

## 제작 방식

GPT-6 Astra와 Codex를 활용해 구현하고, 실제 화면을 반복해서 확인하며 기능·데이터·사용자 경험을 수정했다. 빠른 생성 자체보다 결과를 검증하고 다음 요구사항을 구체화하는 과정을 프로젝트의 핵심으로 삼았다.

## 라이선스

별도의 저장소 라이선스는 아직 지정하지 않았다. 외부 지도와 공개 데이터는 각 제공자의 라이선스와 출처 표기 조건을 따른다.
