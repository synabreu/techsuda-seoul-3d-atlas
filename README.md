# Seoul 3D Atlas

서울 25개 자치구와 주변 지형을 웹 브라우저에서 탐색하는 인터랙티브 3D 도시 아틀라스다. 공개 지도에 교통, 관광, 숙박, 등산로, 문화유산, 주택 정보를 연결해 서울을 한 화면에서 둘러볼 수 있도록 만들었다.

이 저장소에는 Seoul 3D Atlas의 프로젝트 개요, v5.4까지의 버전 기록, 데이터 출처와 처리 규모, 아파트 실거래가 분석, 프로젝트 재현 가이드, AI 에이전트 작업 문서, 발표 자료가 정리되어 있다.

> 정밀 디지털 트윈이나 모든 정보를 실시간으로 제공하는 여행·부동산 서비스가 아니라, 공개 데이터를 연결해 서울을 새로운 방식으로 탐색하는 프로젝트다.

## 최근 업데이트

- 데이터 출처별 URL, 스냅샷 기준일, 사용 범위와 주의사항을 추가했다.
- 서울 25개 자치구와 건물 원본 267,080개를 비롯해 지하철, 버스, 관광 명소, 문화유산 데이터 규모를 구체화했다.
- 아파트 단지 2,887행과 매매 실거래가 원본 189,991행의 정제·표시 기준을 기록했다.
- 초기 버전부터 v5.4까지의 주요 기능 변화를 하나의 버전표로 정리했다.
- AI 에이전트가 프로젝트를 수정할 때 따를 작업 규칙, 아키텍처, 제품 사양, 렌더링, 검증, 배포 문서를 추가했다.
- 발표 자료와 GPT-6 Astra API 전환 참고표를 저장소에서 바로 열 수 있도록 연결했다.
- 한 문장 프롬프트, 상세 재현 프롬프트, 퓨샷 프롬프팅과 반복 배포 방법을 담은 한글 재현 가이드를 추가했다.

## 주요 기능

- 서울 25개 자치구와 건물 원본 약 26만 7천 개를 3D로 표현한다.
- 지도를 회전·확대·축소·이동하고 14개 주요 랜드마크를 자동 비행으로 둘러볼 수 있다.
- 지하철 22개 노선·624개 역의 경로, 중간 경유역과 예상 시간을 탐색할 수 있다.
- 버스 노선·방면·정류장·환승 지점과 진행 상태를 확인할 수 있다.
- 서울과 근교의 등산로, 문화재·관광 명소, 호텔·숙소의 위치와 상세 정보를 표시한다.
- 아파트 단지를 검색하고 매매 실거래가와 전세·월세 정보를 지도에 선택적으로 표시한다. 가격 표시는 기본적으로 꺼져 있다.
- 한국어·영어·일본어·중국어 간체·스페인어·프랑스어·이탈리아어 등 7개 언어를 지원한다.
- KRW·USD·JPY·CNY·EUR 등 5개 통화 표시를 지원한다.
- 낮·노을·야경·비·눈과 봄·여름·가을·겨울을 조합해 도시 분위기를 바꿀 수 있다.
- 데스크톱 마우스와 모바일 터치 조작을 지원한다.

## 프로젝트 재현 가이드

[Seoul 3D Atlas 재현 가이드](./seoul-3d-atlas-reproduction-guide-ko.md)는 다른 사용자도 비슷한 3D 도시 애플리케이션을 만들 수 있도록 프롬프트 작성법과 반복 개발 과정을 정리한 문서다.

- 한 문장으로 Codex에 높은 자율성을 부여하는 시작 방법
- 제품 목표, 데이터 출처, 기능, 성능, 검증과 배포 조건을 포함한 상세 프롬프트
- 최신 Seoul 3D Atlas를 참고 사례로 사용하는 퓨샷 프롬프팅
- 토큰·컴퓨팅 용량 부족 시 추론 수준을 조정하는 방법
- 배포 결과를 직접 확인하고 수정·재배포를 반복하는 검증 방법

핵심은 기술 이름을 나열하는 것이 아니라 원하는 사용자 경험과 프로젝트의 완료 기준을 연결하는 것이다.

## 제한사항

- 건물은 서울 전체를 브라우저에서 표시하기 위해 단순화했다. 높이 정보가 없는 건물에는 층수나 기본값 기반 추정치가 포함될 수 있다.
- 지하철 데이터는 2026년 5월 31일 기준 스냅샷이며 실시간 도착, 지연, 막차와 요금을 제공하지 않는다.
- 버스와 지하철 경로 및 예상 시간은 데이터 기반 참고 정보이며 실제 이동 경로와 다를 수 있다.
- 날씨, 계절, 차량과 선박의 움직임은 시각적 연출이며 현재 서울의 실시간 상태가 아니다.
- 부동산 가격은 정보 탐색용이며 감정가나 AI 가격 예측 결과가 아니다.
- 호텔 표시는 실시간 객실 재고나 예약 가능 여부를 보장하지 않는다.
- 모바일 조작은 지원하지만 기기별 FPS를 정량적으로 측정한 결과는 아직 없다.

## 제작 방식

GPT-6 Astra와 Codex를 활용해 구현하고, 실제 화면을 반복해서 확인하며 기능·데이터·사용자 경험을 수정했다. 빠른 생성 자체보다 결과를 검증하고 다음 요구사항을 구체화하는 과정을 프로젝트의 핵심으로 삼았다.

## 라이선스

별도의 저장소 라이선스는 아직 지정하지 않았다. 외부 지도와 공개 데이터는 각 제공자의 라이선스와 출처 표기 조건을 따른다.
