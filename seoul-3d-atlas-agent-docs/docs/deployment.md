# 빌드 및 OpenAI Sites 배포

## 1. 배포 전 조건

다음 조건을 만족한 뒤 배포한다.

- 프로덕션 빌드 성공
- 핵심 데이터 검증 성공
- 서울 25개 자치구 확인
- 건물 바이너리 검증
- 핵심 입력 기능 검증
- 자동 비행 검증
- 낮/노을/야경 검증
- 데이터 출처와 라이선스 문서화

## 2. 정적 빌드

배포 디렉터리에는 최소 다음이 포함된다.

- HTML
- JavaScript
- CSS
- 건물 데이터
- 필요한 지형 데이터 또는 참조
- 이미지 및 기타 정적 자산

## 3. OpenAI Sites 배포

OpenAI Sites 배포 기능이 실제 작업 환경에서 사용 가능한 경우에만 수행한다.

절차:

1. 프로덕션 빌드 생성
2. 최종 검증 실행
3. Sites 배포 실행
4. 배포 성공 응답 확인
5. 공개 URL 열기
6. 핵심 기능 재검증
7. 공개 URL 기록

## 4. 배포 성공 기준

다음 항목을 모두 확인해야 성공으로 기록한다.

- URL이 실제 존재
- HTTP 접근 가능
- 첫 화면 로드
- 지도 데이터 로드
- 회전/줌/패닝 작동
- 최소 하나의 랜드마크 자동 비행 확인
- 환경 모드 전환 확인

## 5. 배포 실패 시

배포 도구, 권한, 네트워크 또는 환경 문제로 실패하면 다음을 기록한다.

- 실패 단계
- 오류 메시지
- 빌드 상태
- 로컬 검증 상태
- 사용자가 수행해야 할 다음 단계

성공하지 않은 URL을 만들어내지 않는다.

## 6. 완료 보고 예시

```text
빌드: 성공
자치구: 25/25 확인
건물 수: 실제 검증된 값 기록
바이너리 검증: 통과
데스크톱 입력: 통과
모바일 입력: 통과/미검증
자동 비행: 14/14 통과
낮/노을/야경: 통과
OpenAI Sites 배포: 성공/실패
공개 URL: 실제 검증된 URL만 기록
토큰 사용량: 실행 환경에서 확인 가능할 때만 기록
남은 제한사항: 실제 항목 기록
```
