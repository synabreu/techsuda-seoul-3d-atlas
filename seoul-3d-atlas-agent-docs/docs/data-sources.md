# 데이터 출처 및 라이선스 관리

## 1. 목적

Seoul 3D Atlas에서 사용하는 모든 외부 데이터의 출처, 라이선스, 스냅샷 날짜, 변환 방법을 관리한다.

실제 사용하지 않은 데이터 출처는 사용했다고 기록하지 않는다.

## 2. 건물 / 도로 / 수계

권장 출처:

- OpenStreetMap
- OpenFreeMap
- OpenMapTiles 호환 데이터

기록 항목:

| 항목 | 값 |
|---|---|
| 출처명 | 실제 사용한 출처 |
| 원본 URL | 실제 URL |
| 스냅샷 날짜 | 실제 조회/스냅샷 날짜 |
| 라이선스 | 실제 라이선스 |
| 전처리 | 수행한 변환 |
| 비고 | 제한사항 |

## 3. 지형

가능한 출처:

- AWS Terrain Tiles
- Mapzen 계열 terrain
- SRTM 계열 공개 표고 데이터

실제 사용한 출처만 기록한다.

## 4. 자치구 경계

서울 25개 자치구 경계 데이터의 출처와 기준 연도를 기록한다.

현재 행정경계와 차이가 있을 수 있다면 제한사항으로 표시한다.

## 5. 건물 높이

각 건물 높이는 다음 상태 중 하나로 분류할 수 있다.

- 원본 데이터에 높이 존재
- 층수 기반 추정
- 기본값 기반 추정
- 기타 추정

층수 기반 추정식은 실제 구현과 동일하게 기록한다.

## 6. 데이터 단순화

성능을 위해 footprint 또는 도로 geometry를 단순화할 수 있다.

기록 항목:

- 알고리즘
- tolerance
- 좌표계
- 원본 대비 손실 가능성

## 7. 라이선스 표시

웹사이트 정보 패널과 README에는 각 데이터 라이선스가 요구하는 출처 표기를 제공한다.
